## Lessons (add to the recipe)
- **`playwright-cli close` does NOT close the docker Chromium tab**; it keeps rendering at full CPU. Close it with `curl -s --noproxy '*' http://127.0.0.1:9222/json/close/<targetId>` (list targets: `curl -s --noproxy '*' http://127.0.0.1:9222/json`). Check `uptime` (load < 3) before running `npm run e2e`.
- `Systems.openMenu(...)` and `LB.goto(...)` return promises that do not settle quickly: in Playwright flows call them as `page.evaluate(...).catch(() => {})` (do not `await`), like `tests/e2e/smoke.cjs`.
- A foreground `sleep` is blocked; waiting works with `node -e "setTimeout(()=>{},N)"` or a node poll script. Lead scratch (outside the repo, may vanish): `/tmp/orchestrate/lead/{wait-notes.js,wait-chain.js,flow-bulk.cjs,flow-ui.cjs,flow-cal.cjs}`.
