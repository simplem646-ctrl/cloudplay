## Context
- Task #14 in the plan run by the orchestrator. Game: "Bellhaven Days". You write the everyday TALK content for every character except the five love interests (nina, elise, clara, mari, vera: other writers own them) and Theo. The player talks to NPCs constantly: variety and personality here make the town feel alive. Dialogue is game data; the user will read it.
- READ FIRST: `docs/game/03_STORY_BIBLE.md` (sections 1, 3, 5, 6, 9; character voices!), `docs/game/02_SIM_CONTENT_CONTRACTS.md` sections 3 and 9 (dialogue pool format, selection rules, gifts), `src/sim/script_dsl.js` (`validateDialoguePool` + condition grammar for `when`), `src/data/cast.js` (voices, roles, clubs, homes, birthdays), `src/data/calendar.js`, `src/data/items.js` (REAL item ids for gift lists), `src/data/shops.js`, `docs/game/04_WORLD_SPEC.md` (map ids for `map` conditions), `docs/game/api/story_main.md` (main story flags/quests you can reference in `when`), `docs/game/api/sim.md`/`events.md` for how talk selection works (highest `priority` eligible entry wins, ties random; `talk` = first conversation each day, `repeat` = later ones).
- Format: `src/content/dialogue/<npcId>.js` -> `export default { npc, talk:[ {when?, priority?, say:[ 'text' | ['face','text'], ... ]} ], repeat:[...], gift:{ loves:[ids], likes:[], dislikes:[], hates:[], lines:{ loves:[...], likes:[...], neutral:[...], dislikes:[...], hates:[...], birthday:[...] } } }`; line items are `'text'` or `['face','text']` with faces from EXPRESSIONS; each text <= 220 chars (ideal <= 120; boxes show ~38 chars x 3 lines).
- Files and counts: TRIMMED COUNTS (token budget): friends `jules, dante, owen` and `roz` (>= 20 `talk` + 6 `repeat` each); `bruno, kit` (>= 10 + 4); teachers `ms_delaney, mr_brandt, dr_fennel, coach_mitchell, mr_abel, mr_quill, principal_marsh, nurse_hale` (>= 10 + 4 each); townsfolk `mr_finch, mrs_calder, rosa, mr_larkin, tomas, dr_patel, mayor_greer, m_voss` (>= 10 + 4 each); `biscuit` (cat: narration-style lines, >= 8); `_extras.js` exports an ARRAY of pools for `student_01`..`student_14` and `townie_01`..`townie_08` (ids in `EXTRAS`), each >= 6 generic one-liners, varied by season/weather/time/place, with distinct small personalities (e.g. the gossip, the sleepy one, the sports fan, the worried first-year, the fisherman with tall tales).
- Variety dimensions to use in `when`: hearts bands (`hearts`), season, weather, weekday/weekend (`weekday`, `schoolDay`), time of day (`time`), place (`map`), year, festival days (`festival`), clubs/jobs/partner (`club`, `partner`, `dating`), exam weeks (`rank`, `average`, `standing`), main-story progress via flags from story_main.md (`main_bell_story_known`, `main_core_found`, ...), money/items sparingly. Always include generic fallbacks (priority 1, no `when`). Higher hearts = warmer, more personal, hints at backstory; low hearts = polite/guarded for shy characters. Reflect each voice strictly (cast.js `voice`).
- Gifts: loves >= 3, likes >= 4, dislikes >= 3, hates >= 1 (all existing item ids), personality-driven; reaction lines >= 4 per taste category plus 4 birthday lines.
- Never reference UI buttons; English only; no profanity beyond "darn/heck".
