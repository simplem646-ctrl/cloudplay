## Required deliverables (all under `src/scenes/academics/`; `index.js` exports `registerAcademicScenes()` which registers all five)
1. `class` — params `{ period, subject, late, minutes, popQuiz, room }` -> result `{ attended: true, gains, choice, minutes }`. A short charming lesson: classroom backdrop (drawn with UI primitives; blackboard with the subject's title and a sketch/formula appropriate to the subject), the teacher (`teacherOf(subject)`, name from `CAST_BY_ID`) says 1 flavour line picked from a table you write (>= 6 lines per subject, varied by year via `state.time.year`, seeded by day so it does not flicker), then 1-2 attention choices (ListMenu: Listen / Take notes / Doze off / Pass a note) with the consequences described in `academics.md`; if `popQuiz`, ask ONE question from `src/content/exams/<subject>.js` (use `defaultBanks()` from `src/sim/exams.js`; tier by year) with 4 options and call `applyClass(..., { quiz: true|false })`; show the gains as a small result card; the bell rings (`sfx('bell')` if available); advance the clock by `minutes` through `sim.clock.advance` (the sim facade) and pop. PE lessons on the field are the same scene with a field backdrop (room `school_field`). `late` shows a grumble line first.
2. `exam` — params `{ examId, key, subject, slot, late, dayIndex, subjects }` -> result `{ scores: { [subject]: 0..100 }, subject }`. One sitting: title card "Midterm Exams (Term 1) - Day 1 - Mathematics", progress "Question 3/6", question + 4 options (ListMenu); options in `question.struck` are greyed and cannot be chosen (show a tiny "hint" note once when the player has hint level >= 1); no timer; after the last question a result card: written score, bonuses (+conduct, +rested), final score, a teacher/proctor line; PE/art with `prep.practical`: offer the practical via `openScene(game, 'minigame:track_sprint', { context:'exam' })` and if the result has `missing: true`/`cancelled` use `practical: null`; call `submitSubject(...)`; advance the clock 80 min; if `subjects` has a second sitting still pending the director will reopen the scene later (do NOT loop yourself). Use `prepareSubject(state, subject)` at enter (a retry must show the same questions: it is deterministic).
3. `report_card` — params `{ examId, key }` -> `{}`. Parchment look: student name (Theo Hartley), exam label (`EXAMS` in `src/data/calendar.js`), a `drawTable` of the six subjects with score, letter grade (`letterGrade`) and a small bar, average, class rank "n/30", standing, running average, a teacher comment by standing (honors/good/fair/probation; write 3 variants each, warm for good results and gently firm for probation, with the remedial notice when `remedialDays > 0`), and a celebratory banner + jingle (`sfx`) for top-3. Data from `state.school.exams[key]` and `reportCards`.
4. `activity:study_home` and `activity:study_library` — params `{ remedial?, hours?, subject? }` -> `{ minutes, gains }`. Choose subject (list with current knowledge bars; when carried books exist show "book bonus +n") and hours 1/2/3 (disabled options when energy is short), a short animated study scene (desk/books, a lamp or library shelves, a pencil scratching; time-of-day tint), then call `study(state, { subject, hours, place })` with `advanceClock:false`, show per-hour gains + energy cost, advance the clock by `minutes`, pop. `remedial:true` skips the choice screens (forced, 1 hour, given subject) and shows Ms. Delaney's stern-but-kind line.
5. `src/dev/academics_demo.js` harness (real engine + UI, mock sim services; pattern: `src/dev/minigames_demo.js`): `?scene=class|exam|report_card|study_home|study_library`, `window.__ac = { step(n), tap(action), scene(), result() }`.
6. Tests: pure helpers you add (flavour-line selection determinism, question layout/wrapping, grade colours) in `test/scenes/academics_logic.test.mjs`; do NOT duplicate the rule tests.
7. `docs/game/api/academics.md`: append a short "Scenes" section (files, params/results as built, harness URLs). Keep the file under 200 lines.
