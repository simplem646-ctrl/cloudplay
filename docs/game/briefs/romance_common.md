# Romance route brief (common part for S2 and S3)

## Context
- Tasks #11 (S2: Nina, Elise) and #12 (S3: Clara, Mari, Vera) in the plan run by the orchestrator. Game: "Bellhaven Days", a Harvest-Moon-Back-to-Nature-style school life sim, all original. You write the romance routes as GAME DATA. The user will read every line: aim for charm, specificity, humour and heart. Distinct voices, banter over exposition, real stakes, tone-coded choices that matter. All-ages, chaste romance (hand-holding, hugs, blushing, forehead/cheek moment at most, fade-outs). Hard topics are handled warmly.
- READ FIRST: `docs/game/03_STORY_BIBLE.md` (ALL: especially section 4 routes + the canonical event table, section 5-6 for the cast around them, section 9 writing guide, section 10 conventions), `docs/game/02_SIM_CONTENT_CONTRACTS.md` sections 3, 8, 9 (event + dialogue + quest + endings formats), `src/sim/script_dsl.js` (the ONLY ops/conditions allowed; builder helpers `say, narrate, think, choice, opt, iff, warp, place, moveTo, face, pose, emote, cam, fade, flash, lighting, sfx, music, banner, setFlag, friend, money, stat, giveItem, quest, spirit, romance, callScene, ...`), `src/data/cast.js` (each character's `voice`, role, birthday, club), `src/data/calendar.js` (festival ids/dates/places), `src/data/ids.js` (maps, music, sfx, minigames), `docs/game/04_WORLD_SPEC.md` (the maps and their mandatory anchors you may stage on), `src/data/items.js` (REAL item ids for gifts), `docs/game/api/story_main.md` (S1's main-story event ids, flags, quests, festival frames and the festival-evening flags: build your hooks on these), and `docs/game/api/events.md` + `src/sim/mock_stage.js` if present (run your scripts against `MockStage` for crash testing).
- TRIMMED SCOPE (token budget; this supersedes the 10-event plan in doc 03): each heroine needs exactly these canonical events: `_01_meet`, `_02_spark`, `_03_secret`, `_04_festival` (with a short `_04_festival_friend` missed-moment version), `_06_confession`, `_09_promise` (+ `_08_climax` ONLY if you still have budget), plus 2 small hearts-gated slice-of-life events (`<id>_a_*`, `<id>_b_*`). Each event 20-45 ops with real banter and at least one meaningful choice in the big ones. `_05_crisis`, `_07_date`, `_10_farewell` are tier 2 and must NOT be written now. Since `_05_crisis` is skipped, `_06_confession` gates on hearts >= 6 + `seen _03_secret` (not on `_05`), and `_09_promise` on dating + hearts >= 8 in Year 3 Winter 25-28 (or any later day if missed).
- Technical rules (violations fail validation or break the game):
  - Event ids start with the character id. Triggers: `enterMap` (+ optional `time` window), `talk`, `interact`, `wake`, `sleep`, `clock` (at HH:MM, optional map), `auto`. Set `repeat: 'once'` for story beats; `repeat: 'daily'` (+ gating flags) for anything the player might decline and retry, notably the CONFESSION (`<id>_06_confession`): gate it with `noFlag '<id>_dating_since'`-style flags so a "not yet" never locks the route; on acceptance call `romance('<id>', 'dating')` and set a flag.
  - Never hard-lock: wide windows; later fallbacks; if an earlier event was skipped, later events must not become impossible (gate on hearts + `seen` only where the story requires it, and offer a gentle catch-up).
  - Gate dating-only scenes with `{ dating: '<id>' }`; non-dating variants with `{ not: { dating: '<id>' } }`. Only one partner at a time: confession requires `{ partner: null }`.
  - Staging uses anchors from doc 04 (`spot_a..d`, `center`, `entrance`, `npc_*`, map-specific). Start scenes with `fade('out')`/`warp`/`place`, end with `fade('in')` and the player free. Use `emote`, `pose`, `cam`, `lighting`, `music` (ids from MUSIC_IDS: `romantic`, `sad`, `funny`, `tense`, `rooftop`, `observatory`...), `sfx`.
  - `say` text <= 220 chars (ideal <= 150); choices 2-4 options <= 44 chars; faces from EXPRESSIONS; flags snake_case prefixed by the character id; `friend` deltas in points (10 = 1 heart): +3..+6 for good scenes, +8 for a great choice, -3 for a bad one. Use `think` sparingly for Theo.
  - Festival beats: follow doc 03 section 10: trigger `clock` at the festival place and `when: { festival: '<id>', year: n, hearts: [...] }`; the romantic version requires the S1 flag `fest_<festivalId>_y<year>_with_<you>` when that festival offers it; otherwise play a short friend/missed-moment version.
  - Dialogue pool `src/content/dialogue/<id>.js`: `export default { npc, talk:[...], repeat:[...], gift:{loves,likes,dislikes,hates,lines:{loves,likes,neutral,dislikes,hates,birthday}} }` per doc 02 section 9. >= 15 `talk` entries (hearts bands 0-2 / 3-5 / 6-8 / 9-10, a few by season, weather, weekday/weekend or place via `map`, dating variants, post-event lines via `seen`, generic fallbacks with priority 1) and >= 6 `repeat` entries. Gift lists: >= 3 loves, >= 4 likes, >= 3 dislikes, >= 1 hates, ALL real ids from `src/data/items.js`, personality-driven; >= 4 reaction lines per taste + 4 birthday lines. Face codes from EXPRESSIONS.
  - Quest file `src/content/quests/<id>.js` (side quest; `export default { quest_id: { title, summary, steps:[...] } }`) used by `quest` ops in your events.
  - Ending slides `src/content/endings/<id>.js` (`export default { slides: [...] }`): group `romance`, `when: { partner: '<id>' }`, 3 variants by main-story outcome (`{ flag: 'main_vote_saved' }` / `{ flag: 'main_vote_merged' }`) with 1-3 lines <= 90 chars each, warm, specific to their arc.
- Tone calibration: Nina = sunny, loud, teasing, sport-sweaty warmth; Elise = whispering, bookish, intense when enthused; Clara = formal, precise, dry, quietly tender; Mari = chatty, colourful, metaphors, hides depth behind jokes; Vera = deadpan, sparse, unexpectedly soft. Each must feel like a person, not a trope.
